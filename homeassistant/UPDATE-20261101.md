## Log de Actividad / Activity Log

- Sección independiente al final del panel. Un único registro del Engine y el **mismo Store** para avisos HA, tareas Hermes y Proactivo; `snapshot.logs` sigue siendo una API aditiva.
- Retención de los **últimos 200 eventos compartidos**, no 200 entregas ni historial ilimitado. Guardar actividad no cambia revisiones de configuración.
- Metadatos capturados al producirse el evento: origen, tipo, nombre, fecha/hora con segundos en zona HA y resultado/motivo. No se guardan cuerpo, opener, transcripción, URL, tokens ni excepciones privadas. Nombres posteriores de reglas no reescriben eventos antiguos.
- Registros legacy preservados sin inventar origen/tipo; `origin` cron fiable permite atribuir tareas antiguas. No se reconstruye historial proactivo a partir de `last_attempt`/`last_completed`.
- `claimed`, `generating`, `presenting` y `accepted` **no** significan `completed`; ni esos estados acreditan audición o respuesta humana. Se conservan decisiones omitidas, canceladas y fallidas, sin duplicarlas por cada tick.
- El cierre del 27 de octubre indicaba que **todavía no se había registrado un primer evento nuevo enriquecido**. Las ejecuciones naturales de las tres fuentes siguen siendo una observación posterior no acreditada por esta revisión; no se insertan datos ni se fuerza el planificador para aparentarla.

## Invitaciones automáticas cortas, sin truncamiento

El cierre del **29 de octubre de 2026** documenta la única sustitución de `native_transport.py`: una frase completa, una línea, **≤120 caracteres, ≤20 palabras separadas por espacios y ≤240 bytes UTF-8**, incluidos espacios y puntuación. Sin listas, markdown, enlaces ni emojis.

El prompt y la validación al recibir y antes de presentar deben coincidir. Si el texto no cumple, no se envía, no se trunca ni se repite inferencia; sólo se registra el resultado público. El texto válido exacto se conserva para presentación y contexto. La política afecta únicamente al opener automático, no a conversaciones normales, respuestas, cron o avisos HA. No modifica voz, proveedor, modelo, VAD, firmware ni wake word.

Este presupuesto es conservador: no mide el máximo de heap ni garantiza caber simultáneamente en una pantalla. El cierre no hizo una nueva prueba acústica/lectura física ni forzó el planificador; **la primera invitación natural seguía pendiente de observación**. Las pruebas offline no cierran esa limitación.
